# OreSpawn (1.20.1 port)

Private copy for playing with friends.

- `orespawn-1.20.1-port-1.0.0.jar` — port for Minecraft 1.20.1
- `Ore-Spawn-Mod-1.12.2_1.jar` — original mod for Minecraft 1.12.2

## Install
1. Download the jar for your Minecraft version (Code → click the file → Download raw file).
2. Put it in your `.minecraft/mods` folder (needs the matching mod loader installed).
3. Both players need the same jar.
